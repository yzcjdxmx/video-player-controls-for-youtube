# 隐私声明 · Privacy Policy

**Video Player Controls for YouTube** 不收集、不存储、不传输任何个人数据。

## 中文

本扩展:

- **不采集任何数据** —— 没有统计、没有分析、没有崩溃上报。
- **不发出任何网络请求** —— 扩展里没有一处 `fetch` / `XMLHttpRequest` / 远程脚本,权限清单里也没有任何网络权限。
- **只用 `storage` 这一个权限**,且只用来在你自己的浏览器里保存你改的设置(倍速、进度条颜色、默认清晰度等)。这些设置不会离开你的设备;如果你登录了浏览器账号并开启同步,它们会随浏览器自身的同步功能走,与本扩展无关。
- **只在 `www.youtube.com` / `m.youtube.com` 上运行**,读取当前页面的视频元素状态(播放位置、时长、清晰度列表)以显示进度条和设置清晰度。这些信息不会被记录或外发。
- 代码完全开源,可自行审阅:https://github.com/yzcjdxmx/video-player-controls-for-youtube

联系方式 / 报告问题:在上面仓库提 Issue。

## English

This extension collects **no data whatsoever**:

- No analytics, no telemetry, no crash reporting.
- **No network requests**: the code contains no `fetch` / `XMLHttpRequest` / remote scripts, and the permission list contains no network permissions.
- The only permission requested is `storage`, used solely to save your own settings locally in your browser. Nothing leaves your device. (If you have browser sync enabled, those values sync through your browser's own sync feature — unrelated to this extension.)
- It runs only on `www.youtube.com` / `m.youtube.com`, reads the current video element's state (position, duration, available qualities) to draw the progress bar and set the quality. Nothing is logged or transmitted.
- Fully open source: https://github.com/yzcjdxmx/video-player-controls-for-youtube

Contact / issues: open an issue in the repository above.
